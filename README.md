# libqi-py

This library is a partial implementation of Aldebaran NAO middleware named libqi.
Where the original library [libqi-python](https://github.com/aldebaran/libqi-python/) depends on the
C++ native library [libqi](https://github.com/aldebaran/libqi/) which makes distribution on all
platforms difficult, this port is implemented in pure Python.
